<dfn>Time of day</dfn> is a gameplay element in Dota 2 that operates alongside the game's clock. Certain mechanics behave differently depending on the time of day.

As soon as a match starts (after the heroes from both [[factions]] have been shown), the clock starts at one of the following values, depending on the [[game mode]]:
* {{G|clock start regular}} in a regular match.
* {{G|clock start bots}} in a [[Game_modes#Play_vs_Bots|Play vs Bots]] match.
* {{G|clock start turbo}} in a [[Game_modes#Turbo_Mode|Turbo]] match.
** However, [[Game_modes#New_Player_Mode|New_Player_Mode]] starts at {{G|clock start regular}}, despite using the Turbo ruleset. Item availability isn't adjusted here, meaning that because of the extra time spent in the preparation phase, items such as {{I|Aghanim's Shard}} will become available in the shop {{#expr:{{G|clock start turbo}}-{{G|clock start regular}}}} seconds "earlier".<!--https://github.com/ValveSoftware/Dota2-Gameplay/issues/9851-->
* {{G|clock start demo}} in the Demo Hero mode.

==Day-Night Cycle==
[[File:DayNight.png|thumb|The Day/Night indicator in the default [[HUD Skins|HUD]].]]
Each day in Dota 2 is {{#expr:{{G|day duration}}/60}} minutes long, divided evenly between daytime and nighttime. Each match starts out at nighttime during the preparation phase pre-horn. Once the <ab>ambient_horn_radiant.mp3</ab><ab>ambient_horn_dire.mp3</ab> horn sounds (Radiant/Dire) and the game time reaches 0:00, the first dawn starts. The first night begins at {{#expr:{{G|day duration}}/60/2}}:00, the second day starts at {{#expr:{{G|day duration}}/60}}:00, and so on. Shifting from day to night and vice versa is signaled by an audio cue, with nighttime being announced with a wolf's howl <ab>ambient_night.mp3</ab>, while daytime is announced with a bird's tweet and a rooster's crow <ab>ambient_morning.mp3</ab>. Some custom maps may have their own version of these audio cues.

At night, the map is darker and most units experience reduced vision, as detailed below. Additionally, some heroes have their abilities modified according to the time of day, with the most notable example being {{H|Night Stalker}}.

{{Key press|Alt|mouseleft}} the clock prints the time in allied chat, and also prints whether {{Rune|Bounty}} and/or [[Runes|Powerup runes]] are spawning soon.

==Server Ticks==
Article about server ticks. The game server ticks at {{#expr:{{G|tick rate}} round3}}-seconds. This is how often Dota2 sends data between server and client.

The minimum duration for an ability's duration is 1-server tick.
